# Bomstad Display (optional)

The dashboard's typeface, Bomstad Display, is a licensed font. Its files are
**not** in this repository and must never be committed (`.gitignore` keeps
everything in this folder out except this file).

Without the files the dashboard works as it is and draws its text in your
computer's system font. To see it exactly as designed, get the three files
below from your team and put them in this folder, then reload the page:

```
public/fonts/BomstadDisplay-Medium.woff2
public/fonts/BomstadDisplay-SemiBold.woff2
public/fonts/BomstadDisplay-ExtraBold.woff2
```

All three are needed; with one missing the font is not used at all.

---

Dashboard'un yazı tipi Bomstad Display lisanslı bir fonttur; dosyaları bu
repoda yoktur ve asla commit edilmemelidir. Dosyalar olmadan dashboard
sorunsuz çalışır, metinler bilgisayarının sistem fontuyla görünür. Birebir
aynı görünüm için yukarıdaki üç dosyayı ekibinden alıp bu klasöre koyman ve
sayfayı yenilemen yeterli.
